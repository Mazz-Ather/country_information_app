# Country Information App

A Streamlit web application that provides detailed information about countries around the world.

## Live Demo

You can access the live application at:
[https://country-information--app.streamlit.app/](https://country-information--app.streamlit.app/)

## Features

- 🔍 Search for any country by name
- 🏙️ View capital cities
- 👥 Get population statistics
- 📏 See country area in square kilometers
- 💰 Display currency information
- 🌍 Learn about geographical regions
- 🎌 View country flags

## How to Use

1. Enter a country name in the search box
2. Press Enter or click outside the input field
3. View the detailed information about the country
4. Try different countries to explore the world!

## Technical Details

This application is built with:

- **Python**: Core programming language
- **Streamlit**: Web application framework
- **REST Countries API**: Data source for country information (v3.1)
- **Requests**: HTTP library for API calls

## Installation for Local Development

### Prerequisites

- Python 3.7+
